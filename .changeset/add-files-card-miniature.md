Add `GFilesCard` and `GMiniature` from Figma (Card → Files Card, Miniature). `GFilesCard` has `folder` and `file` types, an `actions` slot that does not toggle the card, and a file preview with the extension; `GMiniature` is a selectable 128px thumbnail. Both use `v-model` for the activated state.
